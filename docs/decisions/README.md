# Decisions

One short file per settled design decision, named `YYYY-MM-DD-short-name.md`.
Each says what was decided, why, and where it came from.
These are binding: agents do not re-propose what is recorded here.
To change a decision, add a new dated file that supersedes the old one and mark the old one superseded, with a pointer.
Decisions still open are listed in `docs/setup-and-workplan.md`, Section 3.
